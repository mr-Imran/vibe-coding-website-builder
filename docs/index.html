A free skill for Claude Code and other AI coding agents

Build a real website or web app with AI, even if you can't code

Vibe Coding Website Builder is a free, open-source skill for Claude Code and other AI coding agents. Vibe coding a website is easy to start and easy to get wrong: this skill makes your agent build a simple site, or a full app with sign-in and a database, from your own words, check it for the mistakes you cannot see, and walk you through putting it online.

What you get

A site built from plain words

Tell the agent what the site is for and how people reach you. It builds plain files with nothing to install, and you see the result by double-clicking index.html.

Nothing made up

AI likes to fill gaps with invented customer quotes, prices and opening hours. This skill puts a bright yellow note wherever only you know the answer, so you can see every gap in the browser.

A check before you publish

A score from 0 to 100 and a clear verdict: ready, not yet, or do not publish. Each problem is described by what your visitors would see go wrong.

Forms, payments and bookings

Contact forms, chat links, payment buttons and booking pages are connected through hosted services. No key that should stay secret ever goes into your page.

Click-by-click publishing

One recommended free host with its catch, and numbered steps for your browser. You make the account and you click publish. The agent never asks for a password.

A full app when you need one

Sign-in, roles, a database and your business rules, as one program with nothing to install. Each requirement comes with a test, and you get a table showing which ones pass.

Notes you can read

A plain text file next to your site says how to look at it, how to ask for changes, and how to publish it again later.

Is your AI-built website safe to publish?

The check reads the files of any simple website. It runs nothing, sends nothing and changes nothing. This recording is its real output on a test site that an AI made in a weekend: a payment key was left in the page, the contact form sent messages nowhere, and the main photo would have vanished once the site went online.

You can run it by itself, without an agent:

python3 site_check.py my-site

The score is a checklist of common faults in the files. It does not judge the design, and it cannot tell whether visitors will come. This page scores 100 out of 100 on its own check.

When you need a web app, not just pages

A booking system, a member portal, an order tracker. The skill builds it as one small program with its database in one file, from a starter kit whose sign-in, roles and safety checks are already written and tested. Every app meets the eight mandatory requirements; the advanced ones are built when you ask.

A requirement counts as met only when the app's own test for it passes. An app costs about five US dollars a month to keep awake online and puts other people's data in your care, so when a link to a hosted service would do the job, the skill says so first.

Install it

  1. Get an AI coding agent

    The skill is tested with Claude Code. Other agents that read SKILL.md files should work too.

  2. Add the skill

    Paste this line into a terminal and press Enter. It needs Node.js.

    npx skills add mr-Imran/vibe-coding-website-builder

    In Claude Code you can install it as a plugin instead:

    claude plugin marketplace add mr-Imran/vibe-coding-website-builder
claude plugin install vibe-coding-website-builder@vibe-coding-website-builder

  3. Say what you want

    Open an empty folder with your agent and describe your site in your own words. To check a site you already have, open its folder and ask: Is this OK to publish?

What it will not do

  • Invent customer quotes, numbers, prices or opening hours.
  • Put a secret key or a password in a page.
  • Create accounts, publish, buy a web address or pay for anything. Those are your clicks.
  • Say your site is online before it has seen the address.
  • Fake a log-in inside a page, or build an app when a link to a hosted service would do.
  • Call an app secure. It says what was tested and what was not.
  • Promise visitors or a place in search results.

Questions

What is vibe coding?

Vibe coding means building software by describing what you want to an AI coding agent in plain language, instead of writing the code yourself. The agent writes the files; you look at the result and say what to change.

Do I need to know how to code?

No. You describe the site in your own words. The skill tells the agent to make every technical decision itself, to explain things in plain language, and to give you numbered steps for anything you have to click.

Is it free?

The skill is free and open source under the MIT licence. You need an AI coding agent to run it, such as Claude Code, which has its own price. The hosts it recommends have free plans for a small site, and buying your own web address is optional.

Which AI coding agents does it work with?

It has been tested with Claude Code. It is a plain SKILL.md file with one Python script, so other agents that read skills, such as Codex, Cursor and OpenCode, should work, but that has not been checked yet.

Is my AI-built website safe to publish?

Run the check. It reads the files of any simple website and looks for the faults that are common on AI-built sites: secret keys left in the page, pictures and links that break once the site is online, forms that say thank you and send nothing, stand-in text, and pages that do not fit a phone. It gives a score from 0 to 100 and a verdict: ready, not yet, or do not publish.

Can it build a real app with sign-in and a database?

Yes. For a booking system, a member portal or anything with accounts and rules, it builds one small program with its database in one file and nothing to install, from a starter kit whose sign-in, roles and safety checks are already tested. Each requirement comes with a test. When a link to a hosted service would do the job, such as a payment link or a hosted shop, it recommends that instead, because it is cheaper to run and has less that can go wrong.

Where is my website hosted?

Wherever you choose. A simple site is a folder of plain files, so it works on any host, and the skill recommends a free one. An app needs a host that keeps a program running, which costs about five US dollars a month to stay awake. Either way you get numbered steps for your browser. You create the account and you click publish; the agent never asks for your password.
